# 灵魂三分测试 · PLATO SOUL

柏拉图《理想国》灵魂三分的通俗化改编：12 道情境题，理性 / 激情 / 欲望三个维度，本地算分，生成金（统治者）、银（护卫者）、铜（生产者）三种灵魂类型，三个维度接近时为三元议会。

独立静态网页，无需安装依赖和后端。`index.html` 中包含 HTML、CSS、JavaScript；不接入任何付费功能，不采集答案。

## GitHub Pages 部署

1. 在 GitHub 新建 Public 仓库 `plato-soul-lab`。
2. 将 `index.html`、`.nojekyll` 和本 README 上传到仓库根目录，提交到 `main` 分支。
3. 打开仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 **main**，Folder 选 **/(root)**，保存。
4. 访问 `https://boringY97.github.io/plato-soul-lab/`。
